# Charts657 #

## Description ##

A simple "vibe coded" charts.js examples project.

## Setup ##

## Vendor verisons

    Chart.js: 4.5.1

## For development ##

https://www.chartjs.org/

sudo apt install npm

sudo npm install uglify-js

### Create a new release ###

1. #### uglify ####

uglifyjs charts657.js -c -m -o charts657.min.js

2. #### Run tests ####

3. Update CHANGELOG.md

4. #### Publish to Git ####

```Git
   git commit -a -m 'Cangelog message.'
   git push
```
